# Fonts

Bundled so the app looks the same on every system (Inter, Noto Sans KR, Hack Nerd Font).

- `CoShellSans-*.ttf`: Inter 4.1 (Latin, digits, punctuation) merged with the Hangul of
  Noto Sans KR (static instances at the same weight, scaled to 2048 units/em). Medium uses
  Noto Sans KR Regular. Renamed because modified fonts may not keep the original names.
- `HackNerdFont-*.ttf`: Hack 3.003 patched with icons, from Nerd Fonts 3.5.1 (`Hack.zip`), unmodified.
  Hack is under the MIT License and the Bitstream Vera License: `HackNerdFont-LICENSE.md`. The icon
  sets patched in and their licences are listed in `HackNerdFont-README.md`.

Inter and Noto Sans KR are under the SIL Open Font License 1.1: `Inter-OFL.txt`, `NotoSansKR-OFL.txt`.
