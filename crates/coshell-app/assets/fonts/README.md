# Fonts

Bundled so the app looks the same on every system (design: Inter, JetBrains Mono, Noto Sans KR).

- `CoShellSans-*.ttf`: Inter 4.1 (Latin, digits, punctuation) merged with the Hangul of
  Noto Sans KR (static instances at the same weight, scaled to 2048 units/em). Medium uses
  Noto Sans KR Regular. Renamed because modified fonts may not keep the original names.
- `JetBrainsMono-*.ttf`: JetBrains Mono 2.304, unmodified.

All three are under the SIL Open Font License 1.1: `Inter-OFL.txt`, `NotoSansKR-OFL.txt`,
`JetBrainsMono-OFL.txt`.
